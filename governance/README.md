# Gobierno

Foundation define el proceso; este directorio conserva el ledger de decisiones.
Los conteos vigentes se derivan de `ADR_CATALOG.md` y `RFC_CATALOG.md`; no se
fijan en esta guía.

## Triage

- cambio no estructural y contrato claro → Spec Kit;
- opciones relevantes abiertas → RFC;
- decisión estructural → ADR aceptado antes de implementar;
- cambio constitucional → modifica Foundation solo con autoridad explícita.

Un RFC explora; un ADR decide. Un gate verifica; una persona autorizada acepta.
Después del sello de un release Core, las decisiones de esta genealogía se derogan
mediante otro ADR; no se reescriben silenciosamente.
