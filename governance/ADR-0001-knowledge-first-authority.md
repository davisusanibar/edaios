# ADR-0001 — Autoridad Knowledge First y jerarquía Foundation → Core

**Estado:** Aceptado
**Fecha:** 2026-07-15
**Owner:** Principal Architect

## Contexto

La base inicial necesita una autoridad pequeña que no dependa de semántica
institucional, productos, consumidores o runtimes concretos.

## Decisión

Foundation, Constitución, Ontología, KOM y conocimiento versionado en Git son la
autoridad. La jerarquía instalada termina en **Foundation → Core**. Documentación,
gates, demos y código consumen esa autoridad; no la ratifican. El español es el
idioma normativo. No existen Platform ni Products. Ningún consumer se instala
preventivamente y no se crea licencia raíz.

## Consecuencias

Una extensión futura aporta fuentes y firma humana mediante una decisión nueva.
La ausencia de una instancia significa “no instalada”, nunca “soporte probado”.

## Evidencia y frontera

El árbol y el gate de superficie prueban ausencia local; no prueban adopción,
valor o derecho de publicación.

## Aprobación

Principal Architect · 2026-07-15 · instrucción humana de congelar Core Base.
