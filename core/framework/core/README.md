# Contratos Core

- `docs/`: doctrina, arquitectura, seguridad, memoria, madurez y puertos.
- `profiles/`: Constitución compilada, perfiles acumulativos, políticas y claims.
- `templates/initiative/`: attachment T0 mínimo y explícitamente ilustrativo.
- `../extensions/sdd-adapter/`: interoperabilidad Spec Kit en el borde.

No contiene runtime consumidor, productos, memoria externa, adopciones ni
semántica institucional.
