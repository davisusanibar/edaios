# EDAIOS Core Constitution v1.0.0

Esta constitucion es una proyeccion operativa generica de Foundation. Un
consumer o extensión futura puede agregar restricciones; nunca debilitarlas.

## I. Knowledge First

La verdad durable vive en artefactos versionados. El chat, la memoria del
proceso, los indices y las vistas son reconstruibles y no tienen autoridad.

## II. Human Authority

Toda iniciativa declara owners. Alcance, arquitectura, riesgo, inicio de
implementacion y publicacion requieren un veredicto humano trazable.

## III. Architecture Before Implementation

Los cambios de frontera, autoridad, contrato o dependencia se deciden antes de
implementar y se conservan mediante RFC/ADR.

## IV. Spec Driven Delivery

Intent, requisitos, plan, tareas, pruebas, resultados y outcomes forman una
cadena tipada. Una implementacion sin requisito no es trabajo gobernado.

## V. Verification Before Promotion

Los cambios de codigo siguen red, green, triangulate y refactor. Ningun artefacto
se promueve sin evidencia, gates y estrategia de rollback.

## VI. One Source, Many Views

Git conserva Knowledge Objects y contratos canonicos. Portales, APIs, grafos,
prompts, caches y dashboards se regeneran desde esa fuente.

## VII. Adopt, Adapt, Then Build

Se adopta un estandar probado, se adapta en el borde cuando falta contexto y se
construye solo la capacidad residual que diferencia al sistema operativo.
