# Core Architecture

```text
Foundation
  ├─ Constitution / KOM / Governance
  ↓
Core
  ├─ atomic IO + read-only knowledge
  ├─ schemas + profiles + conformance
  ├─ SDD harness + authority/policies
  ├─ EKG/query local y federado explícito
  ├─ templates y adapters contractuales
  ├─ checksum + SBOM + provenance local
  └─ gates + evidence/approval receipts
  ↓
Initiative attachment
  ↓
Consumer runtime
```

Core coordina y valida; no ejecuta agentes, modelos, data planes, merges o
deploys. Un puerto, schema, fixture o profile no demuestra que su adapter o
iniciativa exista.
