# Modelo de madurez de claims

| Estado | Significado |
|---|---|
| absent | no instalado |
| illustrative | ejemplo didáctico |
| contracted | contrato versionado |
| enforced | contrato ejecutado localmente con pruebas positivas y negativas |
| configuration-tested | configuración validada |
| runtime-tested | ejecución observada en scope declarado |
| operational | operación repetible con evidencia |

La promoción exige evidencia nueva y una frontera explícita. `enforced` no
equivale a `integrated`: un PASS, fixture, configuración o demo no demuestra
adapter externo, adopción, producción u outcome.
