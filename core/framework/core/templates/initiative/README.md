# Initiative attachment T0

Plantilla ilustrativa para que una iniciativa consuma Core sin instalar su
runtime, datos o decisiones dentro de Core. `OWNER-REQUIRED` y
`VALUE-OWNER-REQUIRED` son marcadores: deben ser sustituidos por personas
autorizadas y fuentes reales antes de pedir aceptación.

El attachment empieza en `draft`. Validar el schema no lo registra, no lo
acepta y no demuestra operación remota. Una política hija puede agregar
controles, nunca retirar los heredados de `initiative-adoption`.

La creación segura se realiza con `edaios-core init`; los archivos aquí son la
forma pública y revisable del contrato.
