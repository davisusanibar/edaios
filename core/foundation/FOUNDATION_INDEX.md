# Foundation Index

Foundation 1.0.0 es la única autoridad normativa de EDAIOS.

| Superficie | Propósito |
|---|---|
| `identity/` | nombre, naturaleza y audiencia |
| `vision/`, `mission/`, `values/` | dirección y criterio |
| `manifesto/`, `philosophy/`, `principles/` | tesis operativa |
| `constitution/` | reglas no negociables |
| `ontology/` | tipos y relaciones del sistema |
| `model/` | contrato de Knowledge Objects |
| `governance/` | autoridad, ADR, RFC y promoción |
| `strategy/` | secuencia Foundation → Core → Consumer |

Core materializa Foundation. No hay consumers instalados. Cualquier extensión
futura consume Core sin redefinir esta capa y nace únicamente mediante una
necesidad gobernada.
