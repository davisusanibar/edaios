# EDAIOS Foundation 1.0.0

Foundation define identidad, filosofía, Constitución, Ontología, KOM, estrategia
y gobierno. Es normativa y no contiene runtime, producto, proveedor ni
semántica institucional.

Si una implementación, demo, prompt o conversación contradice Foundation,
prevalece Foundation. Todo cambio de esta capa requiere decisión aceptada,
actualización source-first y recompilación de la Constitución operativa.
