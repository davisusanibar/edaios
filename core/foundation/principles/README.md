# Principios EDAIOS

1. **Knowledge First.** El conocimiento es el producto principal.
2. **Spec before artifact.** El contrato precede a su materialización.
3. **Decision traceability.** Un cambio estructural requiere ADR.
4. **Zero numbers without source.** Cifras y claims declaran fuente y alcance.
5. **One source, many views.** Git conserva; las vistas se regeneran.
6. **AI consumes; humans sign.** La IA no inventa autoridad.
7. **Privacy by Design.** Sensibilidad y autorización preceden el consumo.

Estos principios se verifican mediante contratos y gates, pero su aceptación y
la verdad aportada por un owner siguen siendo humanas.
