## Tesis

> El conocimiento es el producto principal; el software es una consecuencia.

## Desarrollo

Todo sistema construido mediante EDAIOS considera el conocimiento como el activo principal del proceso de ingeniería. El conocimiento incluye: decisiones, principios, hipótesis, contexto, restricciones, aprendizajes y las razones detrás de las decisiones.

Principio constitucional: **ninguna implementación tiene mayor autoridad que el conocimiento que la originó.** El código puede cambiar, la arquitectura puede evolucionar y las herramientas pueden reemplazarse; el conocimiento debe preservarse.

## Representación semántica

- Entidades: `Knowledge Object`, `Decision`, `Principle`.

## Lo que este artículo no pretende decir

- No desprecia el código ni la ejecución; los subordina al conocimiento que los justifica.
