# PREÁMBULO

**Capa:** Foundation v1.0
**Estado:** Ratificado
**version:** 1.0.0
**Deriva de:** `core/foundation/strategy/README.md`

Durante décadas, la ingeniería de software aprendió a gestionar código, infraestructura, procesos y despliegues. Sin embargo, un activo fundamental permaneció disperso: el conocimiento generado durante el proceso de construcción.

La llegada de la Inteligencia Artificial hizo visible un problema que ya existía: las organizaciones no cuentan con mecanismos suficientemente sólidos para preservar, gobernar y evolucionar el conocimiento que guía sus decisiones.

EDAIOS nace de la convicción de que **el conocimiento debe gestionarse con el mismo rigor con el que gestionamos el código fuente**.

Esta Constitución establece los fundamentos que guían la evolución del Framework. Es la autoridad máxima de EDAIOS: ninguna implementación, documentación técnica, plataforma, prompt o agente de IA puede contradecirla. Cuando exista conflicto, prevalece la Foundation y, dentro de ella, esta Constitución.

Quienes adopten EDAIOS —personas y agentes— se comprometen a tratar el conocimiento como el producto principal y al software como su consecuencia.
