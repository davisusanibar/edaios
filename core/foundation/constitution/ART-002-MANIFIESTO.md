## Tesis

> El conocimiento es el producto principal y el software es una consecuencia; la brecha entre estrategia e implementación se cierra con conocimiento compartido.

## Desarrollo

Se ratifican como compromisos constitucionales:

- El contexto pertenece al proyecto, no a una conversación ni a una persona.
- La estrategia se versiona como el código.
- Las decisiones se trazan; no flotan como opiniones.
- La arquitectura se gobierna; no se improvisa.
- Los humanos son responsables; la automatización no es ciega.
- El conocimiento legado se clasifica, no se borra.
- La IA consume la verdad; no la inventa.
- Cualquiera —persona o agente— debe entender el proyecto leyendo el repositorio.
