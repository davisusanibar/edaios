# Superficie diaria de Core EDAIOS

Para comenzar hoy, leer en este orden:

1. `README.md` y `AGENTS.md`.
2. `core/foundation/` para autoridad y Constitución.
3. `core/framework/` para contratos y enforcement.
4. `governance/` para decisiones vigentes; consultar `ARCHIVE_INDEX.md` para contexto histórico.
5. `.specify/` y la feature activa para cambios.
6. `scripts/`, `tools/` y tests para verificación.

`docs/`, `governance/`, `.specify/`, `specs/`, CI y tests son parte del sistema
Core verificable; el índice histórico ayuda a navegar sin borrar trazabilidad.
