# Checklist de calidad de requisitos

- [x] El alcance conserva Core agnóstico: proyecciones y consultas locales,
  sin runtimes, dominios ni autoridad de agentes.
- [x] Los cinco requisitos son observables por compilador, gate, CLI, claims o
  tests versionados.
- [x] Los cinco criterios declaran condiciones verificables sin targets de
  adopción o rendimiento inventados.
- [x] El owner está declarado y la instrucción humana expresa autoriza
  ejecutar estos pendientes del roadmap.
- [x] Las trazas ADR-0002/0003/0007/0008 resuelven contra el catálogo
  compilado.
- [x] La hipótesis de valor no se presenta como outcome; el Value Ledger queda
  N/A hasta existir iniciativas con owners reales.
- [x] La sensibilidad T0 corresponde a metadatos de gobierno y consultas
  locales; sin datasets, PII, secretos ni LLM.
- [x] La CLI declara su frontera en cada salida: consulta, no acepta ni
  publica.
- [x] No queda item crítico pendiente antes del plan.
