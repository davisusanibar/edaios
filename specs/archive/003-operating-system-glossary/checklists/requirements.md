# Checklist de requisitos

- [x] El alcance se limita a la guía derivada, su config, generador y gate.
- [x] Los cinco requisitos son observables y no introducen una dependencia web.
- [x] Los cinco criterios cubren navegación, búsqueda, sensibilidad,
  ambigüedades y regeneración.
- [x] Owner, sensibilidad T0, valor habilitante y frontera de claims están
  declarados.
- [x] ADR-0002 y ADR-0003 son resolubles; el hardening no requiere una nueva
  decisión estructural.
- [x] Las definiciones normativas apuntan a KO, procesos o contratos vigentes y
  las explicaciones derivadas se distinguen de la autoridad.
- [x] FR/SC/T se presentan como identificadores locales de feature; T001 no se
  confunde con el tramo T1.
- [x] ART distingue artículo constitucional de ArtifactRecord según contexto.
- [x] VAL se presenta como referencia no materializada y no como gate o ledger
  activo.
- [x] T1–T3 no reciben una taxonomía inventada; solo se muestran los controles
  que las fuentes vigentes declaran.
- [x] Búsqueda, filtro, contador, estado vacío, no-JS, teclado y responsive son
  verificables.
- [x] No queda item crítico pendiente antes del plan.
