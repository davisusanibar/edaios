# Checklist de requisitos

- [x] El alcance instala únicamente Foundation → Core y explicita lo ausente.
- [x] Los cinco requisitos y cinco criterios son observables por árbol, manifests,
  gates o vista regenerada.
- [x] Owner, sensibilidad T0, valor habilitante y límites están declarados.
- [x] Las trazas resuelven contra los tres ADR aceptados del Core Base.
- [x] La versión 1.0.0 deriva de `VERSION` y los conteos derivan de catálogos;
  no se usa una cifra externa o un outcome sin fuente.
- [x] Las superficies retiradas quedan ausentes; los templates Core no se
  presentan como instancias instaladas.
- [x] Cierre, evidencia y tarea pendiente tienen una semántica inequívoca.
- [x] No queda item crítico pendiente antes del plan.
