# Checklist de requisitos

- [x] El alcance se limita a la guía derivada, su generador y su gate.
- [x] Los cinco requisitos describen comportamiento observable sin imponer una
  biblioteca, framework web o dependencia externa.
- [x] Los cinco criterios cubren sincronización, navegación, accesibilidad,
  límites y regeneración.
- [x] Owner, sensibilidad T0, valor habilitante y frontera de claims están
  declarados.
- [x] ADR-0002 y ADR-0003 son resolubles y no se solicita un cambio estructural
  adicional.
- [x] Las cifras citadas derivan del config vigente y están registradas en
  `evidence/sources.md` con fecha, alcance y rótulo.
- [x] La relación excepcional de dos escenas con una etapa está aclarada y es
  verificable.
- [x] La ausencia de JavaScript conserva contenido legible y la vista sigue
  siendo completamente offline.
- [x] No queda item crítico pendiente antes del plan.
